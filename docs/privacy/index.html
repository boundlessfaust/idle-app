Idle — Privacy Policy

Last updated: May 17, 2026

The short version Idle collects no data. Nothing you do with this extension is transmitted anywhere. Everything stays in your browser.

What Idle does

Idle is a browser extension that detects when you are waiting for an AI response and surfaces a single, research-backed micro-recovery activity. It operates entirely within your browser with no external communication of any kind.

Data we collect

None. Idle does not collect, transmit, store externally, or share any personal data or usage information.

Data stored locally

Idle stores the following data in your browser's local IndexedDB using Dexie. This data never leaves your device:

  • Your extension settings and preferences
  • Activity rotation history (which micro-recovery activities you have recently seen)
  • Panel position on screen
  • Detector failure logs (records of when a site's streaming indicator could not be detected)
  • Mute state and expiry time
  • Pinned write-only note buffer (if you use the WriteOnly capture feature)

All locally stored data is user-clearable from the Options page at any time.

Prompt capture (opt-in, off by default)

Idle includes an optional feature that can display your most recent AI prompt inside certain activity cards to help you stay in context. This feature is:

  • Off by default — you must explicitly enable it in Settings
  • Session-scoped only — the captured text is cleared when you start a new prompt
  • Never stored across sessions
  • Never transmitted outside your browser under any circumstances
  • Limited to the single most recent message — no conversation history is accessed

Permissions used

Idle requests the following browser permissions:

  • storage — to save your settings and activity history locally in IndexedDB
  • tabs — to detect which AI site is active and coordinate wait state across tabs
  • commands — to support the manual hotkey (Ctrl/Cmd+Shift+L)
  • scripting — to inject the activity panel into supported AI sites

No permission is used to access, read, or transmit your browsing history, personal information, or any content beyond what is necessary to detect AI response wait states on the four supported sites.

Third-party services

None. Idle makes no network requests. There are no analytics SDKs, tracking pixels, crash reporters, or external API calls of any kind.

Supported sites

Idle injects a content script only on the following sites:

  • claude.ai
  • chatgpt.com
  • gemini.google.com
  • perplexity.ai

The extension is inactive on all other sites.

Children's privacy

Idle does not knowingly collect any information from anyone, including children under the age of 13.

Changes to this policy

If this policy changes materially, the updated policy will be published at this URL with a revised date. Continued use of the extension constitutes acceptance of the updated policy.

Contact

Questions about this privacy policy can be directed to the extension's developer via the Chrome Web Store listing page.
